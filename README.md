# commute-assistant — 퇴근길 실시간 이동비서

평일 저녁 6시가 되면 화면 가운데에 로봇 알림창이 뜹니다.

> **잔업 및 추가공부를 하시나요?**  [예] [아니요]

**아니요**를 누르면 집까지 가는 가장 빠른 지하철·버스를 바로 알려줍니다.

> **18:20 부천역 1호선 소사 방면 있습니다. 서두르세요!**
> 도착 예정 19:10 · 소요 50분 · 환승 2회 / 곧 비 예보 (19시쯤) · 우산 챙기세요 · 기온 12도

**예**를 누르면 몇 시까지 하는지 물어보고, 그 시각 10분 전에 같은 안내를 해줍니다.

Windows 전용 [Claude Code](https://claude.com/claude-code) 플러그인입니다. 교통 정보는 PlayMCP 교통 도구(MCP)로 실시간 조회합니다.

## 1. 시작하기 전에 (준비물 체크리스트)

아래 4가지가 되어 있어야 합니다. 하나라도 빠지면 알림이 오지 않거나 경로가 나오지 않아요.

- [ ] **Windows 10 / 11** (Mac·Linux는 지원하지 않습니다)
- [ ] **Claude Code 설치 + 로그인.** PowerShell을 열고 `claude --version` 을 입력했을 때 버전이 나오면 OK입니다.
- [ ] **claude.ai 계정에 PlayMCP(교통) 커넥터 연결.** 이 플러그인에 들어 있지 않아서 직접 연결해야 합니다.
  - 확인 방법: Claude Code 안에서 `/mcp` 를 입력했을 때 목록에 `claude.ai PlayMCP` 가 연결됨으로 보이면 OK입니다.
- [ ] **PowerShell 스크립트 실행 허용.** 일부 PC는 기본으로 막혀 있습니다. PowerShell에서 `Get-ExecutionPolicy -Scope CurrentUser` 를 입력해 `Restricted` 나 `Undefined` 가 나오면 아래를 한 번 실행하세요.
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
  (내가 직접 받은 스크립트는 실행하고, 인터넷에서 내려받은 서명 없는 스크립트는 막는 일반적인 설정입니다.)

> **참고:** 이 플러그인은 PC가 **켜져 있고 로그인된 상태**에서만 알림이 옵니다. 꺼져 있던 시간의 알림은 나중에 따라잡지 않습니다.

## 2. 설치

Claude Code를 열고 아래 두 줄을 차례로 입력합니다.

```
/plugin marketplace add number6823/commute-assistant
/plugin install commute-assistant@commute-assistant-market
```

그다음 **Claude Code를 한 번 완전히 종료했다가 다시 실행**하세요. 새로 시작할 때 플러그인의 훅이 "평일 18:00 알림 예약"을 Windows 작업 스케줄러에 자동으로 등록합니다.

> 설치 없이 코드만 내려받아 쓰고 싶다면 `git clone` 후 폴더 안에서 `.\scripts\register-schedule.ps1` 을 실행하면 같은 예약이 등록됩니다.

## 3. 제대로 설치됐는지 확인하기

### ① 예약이 등록됐는지
PowerShell에서:
```powershell
Get-ScheduledTask -TaskName ClaudeCommuteAssistant
```
`State` 가 `Ready` 로 보이면 등록 완료입니다. "찾을 수 없습니다" 가 나오면 Claude Code를 완전히 종료했다가 다시 켜 보세요.

### ② 지금 바로 한 번 체험해 보기
18:00까지 기다릴 필요 없이, 알림 흐름을 지금 실행해 볼 수 있습니다.
```powershell
Start-ScheduledTask -TaskName ClaudeCommuteAssistant
```
화면 가운데에 로봇 알림창이 뜨면 **아니요 → 집 주소 입력 → 출발지 확인(Enter)** 순서로 눌러 보세요. 몇 초 뒤 경로 안내창이 나오면 성공입니다.

처음에는 **집 주소를 한 번 물어봅니다.** 집 근처 **역 이름이나 동네 이름**을 적으세요. (예: `수원역`, `부천역`) 한 번 입력하면 저장되어 다시 묻지 않습니다.

### ③ 채팅으로도 물어볼 수 있어요
Claude Code에서 `/commute` 를 입력하거나 "지금 부천역에서 집까지 뭐 타야 해?" 처럼 물어보면 같은 정보를 채팅으로 알려줍니다.

## 4. 매일 이렇게 동작해요

```
평일 18:00 (월~금, Windows 작업 스케줄러)
  └ 로봇 알림창 "잔업 및 추가공부를 하시나요?"   [예] [아니요]   ← 2분 안에 안 누르면 그냥 닫힘
      │
      ├ [아니요] = 집에 갈래요
      │    1. 출발지 확인창: "지금 어디서 출발하세요?"  (평소 있는 곳이 미리 채워져 있어요. 맞으면 Enter)
      │    2. 약 15초 기다리면 (교통 조회 중)
      │    3. 경로 안내창: "18:20 부천역 1호선 소사 방면 있습니다. 서두르세요!"
      │
      └ [예] = 더 있다 갈래요
           1. 입력창: "몇 시까지 하시나요?"   예) 20:30
           2. "20:20 에 다시 알려드릴게요" 확인창
           3. 종료 10분 전에 자동으로 위의 1~3번이 이어서 나옵니다
```

### 지하철인지 버스인지 어떻게 정하나요
도착지를 넣으면 교통 도구가 버스와 지하철을 모두 비교해서 **가장 빨리 도착하는 경로**를 고릅니다. 버스가 제일 빠르면 버스로 안내하고, 안내 문구의 첫 줄에 처음 타는 것이 `1호선`인지 `66번 버스`인지 노선 이름으로 보여줍니다.

버스만/지하철만 같은 다른 경로가 더 빠를 수 있을 때(지금 고른 차를 오래 기다려야 하는 경우)는 한 줄 힌트가 더 붙습니다.
> 버스(66번)가 더 빠를 수 있어요 (약 13분)

다만 카카오맵처럼 모든 경로를 늘어놓고 비교하지는 못합니다. 교통 도구가 대표 경로 하나와 일부 대안만 알려 주기 때문이고, 버스를 기다리는 시간은 알 수 없어서 힌트는 "~일 수 있어요"로만 말합니다.

### 시각은 이렇게 적어도 돼요
`20:30` · `2030` · `20시 30분` · `20시` · `8시 30분` (이미 지난 시각이면 오후로 봅니다)

### 알아두면 좋은 동작
- **"몇 시까지"를 늦게 말하면?** 교통 정보는 *지금 시각* 기준으로만 조회할 수 있어서, 입력한 시각의 10분 전에 그때 조회합니다. 그래서 알림이 즉시 오지 않고 예약된 시각에 옵니다.
- **재알림은 컴퓨터를 끄면 사라집니다.** (재부팅하면 다시 "예"를 눌러 예약해야 해요.)
- **출발지는 항상 한 번 확인받습니다.** 위치 추정이 틀릴 수 있어서입니다.
- 경로 안내창은 클릭하면 닫히고, 클릭하지 않으면 2분 뒤 저절로 닫힙니다.

## 5. 설정 바꾸기

### 집/평소 있는 곳 바꾸기 (이사했거나 잘못 적었을 때)
```powershell
powershell.exe -NoProfile -File "<플러그인 폴더>\scripts\commute.ps1" -Mode setup
```
입력창이 3개 차례로 뜹니다: ① 집 ② 평소 퇴근/하교하는 곳(학교·학원·직장) ③ 기상청 키(선택, 없으면 비워 두기). 이미 적힌 값은 미리 채워져 있어서 바꿀 것만 고치고 Enter를 누르면 됩니다.

> **`<플러그인 폴더>` 를 모르겠다면** PowerShell에서 아래를 실행하면 경로가 나옵니다.
> ```powershell
> Get-ChildItem "$env:USERPROFILE\.claude\plugins" -Recurse -Filter commute.ps1 | Select-Object -ExpandProperty FullName
> ```

### 알림 시각 바꾸기 (18시가 아닐 때)
```powershell
powershell.exe -NoProfile -File "<플러그인 폴더>\scripts\register-schedule.ps1" -Time 17:30
```
평일(월~금) 17:30으로 바뀝니다. 다시 실행하면 언제든 다시 바꿀 수 있어요.

### 저장되는 설정 파일
위 입력창에서 적은 값은 `C:\Users\<내 이름>\.claude\commute\config.json` 한 파일에 저장됩니다. 메모장으로 직접 고쳐도 됩니다.

| 항목 | 의미 | 기본값 |
|---|---|---|
| `home` | 집 (역/동네 이름) | 처음 한 번 입력 |
| `usual_place` | 평소 있는 곳. 출발지 확인창의 기본값 | 마지막에 확인한 출발지 |
| `remind_minutes_before` | "예"를 눌렀을 때 종료 몇 분 전에 알릴지 | `10` |
| `kma_key` | 기상청 인증키 (선택) | 비어 있음 |

예시 파일은 `config.example.json` 입니다. **이 설정 파일은 내 PC에만 있고 GitHub에는 올라가지 않습니다.**

## 6. 날씨 (선택)

경로 안내창 아래에 `곧 비 예보 (19시쯤) · 우산 챙기세요 · 기온 12도` 같은 한 줄이 붙습니다. **아무 설정 없이도 나옵니다.**

| 상황 | 쓰는 날씨 서비스 |
|---|---|
| 기상청 인증키를 넣었을 때 | 기상청 초단기예보 (공공데이터포털 OpenAPI) |
| 키가 없거나, 기상청 호출이 실패했을 때 | [Open-Meteo](https://open-meteo.com) (키 필요 없음. 기상청 데이터는 아닙니다) |
| 둘 다 실패했을 때 | 날씨 줄만 빠지고 길 안내는 그대로 나옴 |

앞으로 약 3시간 안에 비·눈이 오면 "곧 비 예보 / 곧 눈 예보"로 알려주고, 아니면 "맑음 · 기온 N도" 같이 보여줍니다.

### 기상청 키 발급 (원하는 사람만)
1. [공공데이터포털](https://www.data.go.kr) 에 가입하고 로그인합니다.
2. **"기상청_단기예보 ((구)_동네예보) 조회서비스"** 를 검색해 **활용신청** 합니다.
3. **마이페이지 → 데이터활용 → Open API → 활용신청 현황** 에서 상태가 **승인**이 될 때까지 기다립니다. (최대 1~2시간)
4. 해당 서비스를 눌러 **일반 인증키(Decoding)** 의 복사 버튼으로 복사합니다. Encoding 키도 됩니다.
5. 위 [설정 바꾸기](#집평소-있는-곳-바꾸기-이사했거나-잘못-적었을-때)의 `-Mode setup` 3번째 입력창에 붙여 넣습니다.

> **주의:** 구글(Google) API 키 등 다른 서비스의 키와 헷갈리지 마세요. 구글 키는 `AIza` 로 시작하고 39자입니다. 공공데이터포털 키는 그보다 훨씬 깁니다. 다른 키를 넣으면 기상청이 거부하고, 자동으로 Open-Meteo가 대신 쓰입니다.

## 7. 문제가 생겼을 때

### 18:00이 됐는데 알림창이 안 떠요
1. PC가 18:00에 **켜져 있고 로그인**되어 있었나요? (꺼져 있던 시간은 따라잡지 않습니다)
2. 예약이 있는지 확인: `Get-ScheduledTask -TaskName ClaudeCommuteAssistant`
3. 마지막 실행 결과 확인: `Get-ScheduledTaskInfo -TaskName ClaudeCommuteAssistant` 의 `LastTaskResult` 가 `0` 이면 정상 실행된 것입니다. 0이 아니면 아래 "스크립트 실행이 막혀요"를 확인하세요.
4. 직접 실행해 보기: `Start-ScheduledTask -TaskName ClaudeCommuteAssistant`
5. 그래도 없으면 Claude Code를 완전히 종료했다가 다시 켜서 예약을 다시 등록시키세요.

### "경로를 찾지 못했어요" 라고 나와요
- **수도권(서울·경기·인천) 밖**은 지원하지 않습니다.
- 집이나 출발지 이름이 **오타이거나 너무 모호**할 수 있습니다. `-Mode setup` 으로 `부천역`, `수원역` 처럼 **역 이름**으로 다시 적어 보세요.
- 교통 서버가 잠시 불안정할 수 있습니다. 잠시 뒤 다시 시도하세요.

### 안내가 계속 시간이 오래 걸리거나 "응답이 없거나 시간이 초과됐어요" 가 나와요
교통 조회는 `claude` 를 한 번 더 실행해서 하기 때문에 보통 **10~20초** 걸립니다. 90초를 넘기면 중단됩니다. 다음을 확인하세요.
- Claude Code에 **로그인**되어 있나요? (`claude` 를 실행해 로그인 상태 확인)
- `/mcp` 에서 **PlayMCP가 연결됨**으로 보이나요?

### 출발지가 엉뚱하게 채워져요
위치를 정확히 알아낼 수 없을 때(대부분의 데스크톱 PC)는 인터넷 주소(IP)로 대략적인 위치만 알 수 있습니다. 이 위치는 **서울시청처럼 도시 중심으로 나오는 등 부정확**해서 쓰지 않고, 대신 `usual_place`(마지막에 확인한 출발지)를 보여줍니다. 알림창에서 직접 고쳐 쓰면 됩니다.
노트북이라면 **설정 → 개인 정보 및 보안 → 위치** 를 켜면 가장 가까운 역을 자동으로 찾아 줍니다.

### 알림창의 한글이 깨져요
PowerShell 스크립트는 한글이 깨지지 않도록 **UTF-8 (BOM 포함)** 으로 저장되어 있어야 합니다. 메모장 등으로 `.ps1` 파일을 직접 고쳤다면 같은 형식(UTF-8 with BOM)으로 저장하세요.

### 스크립트 실행이 막혀요 ("이 시스템에서 스크립트를 실행할 수 없으므로…")
[준비물](#1-시작하기-전에-준비물-체크리스트)의 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` 를 실행하세요.

### 날씨 줄이 안 나와요
- 인터넷에 연결되어 있는지 확인하세요.
- 출발지 이름이 지도에서 찾아지지 않으면(예: 너무 모호한 이름) 날씨만 빠집니다. 역 이름으로 다시 적어 보세요.
- 날씨는 길 안내에 꼭 필요한 정보가 아니라서, 실패해도 안내는 그대로 나옵니다.

## 8. 지우기

1. **예약 삭제** (PowerShell): `powershell.exe -NoProfile -File "<플러그인 폴더>\scripts\register-schedule.ps1" -Remove`
2. **플러그인 삭제** (Claude Code): `/plugin uninstall commute-assistant@commute-assistant-market`
3. **내 설정 삭제** (선택): `C:\Users\<내 이름>\.claude\commute` 폴더를 지웁니다. 저장해 둔 집 주소와 키가 같이 사라집니다.

> 플러그인만 먼저 지우면 예약이 남아 알림창이 계속 뜰 수 있으니, **1번을 먼저** 해 주세요.

## 9. 개인정보와 제한사항

### 어떤 정보가 어디로 가나요
| 정보 | 보내는 곳 | 이유 |
|---|---|---|
| 집·출발지 이름 | Claude → PlayMCP(카카오) | 교통 경로 조회 |
| 출발지 이름 | OpenStreetMap Nominatim | 날씨용 좌표 변환 |
| 출발지 좌표 | 기상청 또는 Open-Meteo | 날씨 조회 |
| 내 IP 주소 | ipwho.is | Windows 위치 서비스가 꺼져 있을 때의 대략적 위치 |

집 주소와 기상청 키는 **내 PC의 `config.json` 에만** 저장됩니다. 다른 사람과 공유되지 않고, 이 저장소에도 올라가지 않습니다.

### 제한사항
- **Windows 전용**입니다.
- 교통 정보는 **수도권(서울·경기·인천)** 만 지원합니다. 버스 도착 정보는 경기도 정류장만 지원합니다.
- 교통 정보는 **지금 시각만** 조회됩니다. 미래 시각의 시간표는 볼 수 없습니다.
- 환승이 있는 경로는 안내창에 **처음 타는 차**를 중심으로 보여줍니다.
- PC가 꺼져 있거나 로그아웃된 시간의 알림은 따라잡지 않습니다.

## 10. 구성 파일 (개발자용)

| 요소 | 파일 | 역할 |
|---|---|---|
| MCP | PlayMCP `transit-*` 도구 | 경로·실시간 도착 조회 (이 저장소에 포함되지 않음) |
| Skill | `skills/commute/SKILL.md` | `/commute` 로 채팅에서 바로 조회 |
| Agent | `agents/commute-assistant.md` | 교통 도구만 쓰는 이동비서 에이전트 |
| Hook | `hooks/hooks.json` | SessionStart 때 평일 18:00 예약이 등록돼 있는지 확인, 없으면 등록 |
| 알림창 | `scripts/commute-popup.ps1` | 예/아니요·입력·안내 3가지 모드의 로봇 알림창 |
| 흐름 | `scripts/commute.ps1` | `-Mode ask` / `remind` / `setup` |
| 위치 | `scripts/get-location.ps1` | Windows 위치 서비스 → IP 위치 순으로 시도 |
| 날씨 | `scripts/get-weather.ps1` | 기상청 초단기예보 → 실패 시 Open-Meteo |
| 예약 | `scripts/register-schedule.ps1` | 작업 스케줄러 등록 (`-Time`, `-Remove`, `-EnsureOnly`) |

> **왜 Hook만으로 18:00 알림을 못 하나요?** Claude Code의 Hook은 "세션 시작", "도구 사용 전후" 같은 *이벤트*에만 반응하고 시각 트리거가 없습니다. 그래서 실제 18:00 실행은 Windows 작업 스케줄러가 맡고, Hook은 그 예약이 항상 등록돼 있도록 보장합니다.

```powershell
claude --plugin-dir <이 폴더>          # 플러그인 로드
claude plugin validate .               # 구조 검사
powershell.exe -NoProfile -File scripts\commute.ps1 -Mode ask   # 알림 흐름 수동 실행
```
